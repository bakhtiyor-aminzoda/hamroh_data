## 🎯 Главные инсайты аудита

1. **Опережающий рост спроса пассажиров:** Спрос пассажиров растет в **5.7 раз быстрее**, чем предложение водителей (+46.6% против +8.1% YoY). Это доказывает эффективность Demand-маркетинга.
2. **Дисбаланс предложения:** В системе по-прежнему наблюдается структурный перекос в сторону предложения водителей (~66% поездок). Автопарк простаивает без достаточного числа попутчиков.
3. **Концентрация направлений:**
   * **Душанбе ⇄ Худжанд** формирует свыше **60%** платформы (4 200+ поездок в год).
   * **Худжанд ⇄ Ойбек** формирует **12%** платформы и является естественным трансграничным шлюзом на Ташкент.
   * PM-решение: 100% маркетингового бюджета направляется на эти две ключевые артерии.
4. **Разрыв с финансовым планом ССП (2.23 млн TJS):** Фактические сборы за полугодие составили 2.7k TJS из-за добровольного характера пополнений. Необходим переход к обязательному депозиту/автоматическому списанию комиссии (5–10%) через эквайринг перед публикацией рейса.

## 🚀 Установка и воспроизведение аналитики

`ash
# Клонирование репозитория
git clone https://github.com/bakhtiyor-aminzoda/hamroh_data.git
cd hamroh_data

# Создание и активация виртуального окружения
python -m venv .venv
# Windows:
.\.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# Установка библиотек
pip install -r requirements.txt
`
